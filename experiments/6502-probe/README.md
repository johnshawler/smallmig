# Original 6502 probe

Original 0BSD movement/collision/score fixture and restricted native translation experiment. It does not implement a general 6502 or NES emulator. From the repository root, `python3 experiments/6502-probe/run_test.py` builds and tests it after host tools and private A1200 Kickstart are configured. See the root README for setup. Results are written under ignored build/evidence directories.
