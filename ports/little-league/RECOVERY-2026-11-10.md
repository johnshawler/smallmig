# Reproducible older-source recovery

The starting point is commit `8393b517b49d82137c37d0ef1a1a108254d072d7` from November 7. This is the older original-engine port with interpreter fallback and Fast RAM, not a recovery of later workspace-only native conversions. Earlier validation documents remain historical rather than automatically becoming fresh results.

## Build compatibility

GNU assembler 2.44 rejected three short branches to the forward global symbol `rt_wr_gen`. A local alias at the exact same address resolves this without widening instructions or changing the exported entry. The intended short encodings are retained. An independent diagnostic comparison against a non-exported target produced byte-identical linked code, including CHECK and TRACE variants.

`tests/check_rt_x_branches.py` checks all eight CHECK/STATS/TRACE combinations and 24 exact branch targets/encodings. The native translator CI job now runs this check too. Locked, signature-verified Debian cross tools can be restored with `tools/recovery-m68k/`.

## Fresh checks

- 588 APU checks pass.
- Nine 6,000-frame host graphics scripts pass: 53,991 compared pictures in total, each matching the internal reference. This is not native Amiga picture validation.
- 1,131 native68020 translator programs pass 36,192 executions with exact register/flag/memory/I/O-cycle checks.
- Two private ADF builds are byte-identical: SHA256 `b40f6c298e1517d1a4a6ca5e9c3361490668aaf616900d3d64cbbf1bbcf45deb`.
- A fresh 3,000-field PUAE boot completes with the game introduction visible and 1,107 source frames executed. It uses PAL 68020/AGA, 2 MiB Chip and explicitly verified 8 MiB Z2 Fast, no JIT/FPU/MMU, and cycle-exact CPU/memory/blitter settings. This includes startup and is not a steady-state speed measurement.
- The build requests 2,755,032 Fast bytes; its documented capacity requirement remains at least 4 MiB. It is not a zero-Fast stock build.

A private frontend initially failed during memory-map dumping because it retained temporary callback descriptors. Copying that metadata fixed the frontend; the repeated frame and Chip-RAM captures were byte-identical. The failed run is retained and is not counted as a successful emulator exit.

See `measurements/2026-11-10-recovery.json` for hashes and scope. ROM, firmware, ADFs and captures stay private. Full-match revalidation, broader native graphics/input/audio tests, stock-memory reduction and full-speed acceptance remain open. No new speed claim is made.

## Reproduce

After activating the cross tools, supply the verified private USA cartridge and A1200 firmware as described in README.md:

```sh
python3 ports/little-league/tests/check_rt_x_branches.py
XL_DIRECT_FIXED_IO=1 make -C ports/little-league/vendor/tests/xlunit TRIALS=32 QEMUFLAGS='-cpu m68020 -one-insn-per-tb'
python3 ports/little-league/check.py --rom /private/little-league.nes --frames 6000
python3 ports/little-league/build.py --rom /private/little-league.nes --kickstart /private/A1200.rom
```
